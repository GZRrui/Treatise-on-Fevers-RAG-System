# ADR-0001：隔离高阶原型并建立可复现基线

- 状态：已接受
- 日期：2026-08-06
- 决策范围：阶段 0

## 背景

原始提交 `37d2c122cee1956c83d99f64996b4f15976053d4` 之后的工作区同时包含阶段 0、阶段 1、阶段 1.5 和阶段 2 的未提交成果。直接回退会丢失成果，整体提交又无法证明阶段 0 没有行为重构。

本机执行环境为 Python `3.11.15`、Node.js `22.17.0` 和 npm `10.9.2`。Windows 2025 runner 不提供 CPython 3.11.9 之后的官方 Windows 安装包，因此 CI 固定为同一 ABI 系列的 Python `3.11.9`；Node/npm 仍精确固定为 `22.17.0`/`10.9.2`。后续变更若要升级 Python 次版本或 Node/npm，必须另建兼容性证据，不得静默漂移。

## 决策

1. 将完整混合工作区保存到 `codex/pre-phase-high-order-snapshot`，快照提交为 `94e22e0`。
2. 从原始提交建立 `codex/phase-0`。
3. 仅迁入依赖锁、环境契约、数据审计、原始系统快照和治理资产。
4. 不迁入证据策略、索引 generation/CAS、管理安全接口、前端协议或业务链路修改。
5. 后续阶段按缺陷台账逐项从快照中重做或选择性迁移，禁止整体合并快照提交。

## 结果

阶段 0 可独立安装、验证和回滚。高阶成果仍由独立分支和提交保留，但其代码尚未经过对应阶段验收，不能直接发布。

## 回滚

- 查看原始系统：`git switch main`
- 恢复完整高阶快照：`git switch codex/pre-phase-high-order-snapshot`
- 回到阶段 0：`git switch codex/phase-0`

切换前必须保持工作区干净；不得用强制重置覆盖未提交成果。
